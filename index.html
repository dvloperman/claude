NO HEAD-TO-HEAD RUN PUBLISHED

We won’t turn separate scorecards into a race.

We have not run a controlled Claude Code vs. Codex evaluation for this site. In the sources reviewed, we have not identified a current independent comparison with matched tasks, pinned versions, and a shared protocol that we can responsibly present as a direct winner comparison.

RESULT—NOT MEASURED
THE TEST WE WOULD TRUSTPROTOCOL PROPOSAL · NOT EXECUTED
01

Same task set

Fresh, isolated repository snapshots with tasks spanning bug fixes, feature work, and maintenance.

02

Pin the setup

Record agent and model versions, settings, tools, budgets, environment, and exact prompts.

03

Run fairly

Use matched limits, multiple trials where practical, and randomized order to reduce run-order effects.

04

Judge the patch

Run hidden tests, review regressions and maintainability, and publish raw artifacts with limitations.
